Godot Engine 4.x를 공부하면서 쓸 수 있는 개인 학습 도우미입니다.  
용어 정리, 코드 스니펫 보관, 단계별 가이드, 퀴즈까지 한 페이지에서 해결!

## ✨ 기능

### 📖 용어/개념
- Godot 핵심 용어 23개 기본 수록 (노드, GDScript, 물리, UI, 시그널, 대화창 등)
- 학습 상태 표시: **모름 → 헷갈림 → 이해함** (클릭으로 전환)
- 내 메모 추가 가능

### 💻 코드 스니펫
- 자주 쓰는 GDScript 패턴 13개 기본 수록
- 캐릭터 이동, 충돌 감지, 대화창 시스템, 선택지 분기 등
- **GDScript 신택스 하이라이팅**
- 원클릭 코드 복사

### 🖱️ How-to 가이드
- "이걸 하려면 이렇게 클릭" 스텝별 가이드 11개 수록
- 프로젝트 생성부터 대화창 UI 구성까지

### 🧠 퀴즈 모드
- 용어장 기반 4지선다 퀴즈
- **용어 → 설명** 또는 **설명 → 용어** 모드
- **약점 공략**: 모름/헷갈림 항목만 모아서 집중 복습
- 결과에 따라 학습 상태 자동 업데이트

### 기타
- 📌 즐겨찾기 (핀 고정)
- 🌙☀️ 다크/라이트 테마 전환

## 🚀 사용 방법

### 그냥 쓰기
`index.html` 파일을 브라우저에서 열면 바로 사용 가능합니다.  
별도 서버나 설치가 필요 없어요.

### GitHub Pages로 배포하기

1. 이 리포지토리를 Fork하거나, 새 리포지토리를 만들어 `index.html`을 업로드
2. 리포지토리 **Settings** → **Pages**
3. Source를 **Deploy from a branch**로 선택
4. Branch를 **main**, 폴더를 **/ (root)** 로 선택 후 Save
5. 1~2분 후 `https://유저이름.github.io/리포지토리이름/` 에서 접속 가능!

## 💾 데이터 저장

- 모든 데이터는 **브라우저 localStorage**에 자동 저장됩니다.
- 다른 기기로 옮기려면 **↓ 내보내기**로 JSON 파일을 저장한 뒤, 다른 기기에서 **↑ 불러오기**로 불러오세요.
- **↺ 초기화** 버튼으로 기본 데이터로 되돌릴 수 있습니다.
