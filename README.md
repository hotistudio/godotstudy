# 🎮 Godot 학습 도우미

Godot Engine 4.x를 공부하면서 쌓이는 용어, 코드 패턴, 삽질 기록을 한 곳에서 관리하는 개인 학습 노트 웹앱입니다.

**HTML 파일 하나로 동작**하며, 서버 없이 로컬·GitHub Pages·PWA 설치 모두 지원합니다. 모든 데이터는 브라우저의 `localStorage`에 저장되므로 외부 전송 없이 완전히 로컬에서만 굴러갑니다.

---

## ✨ 주요 기능

- **📖 용어/개념** — Godot 노드, GDScript 문법, 물리/UI/시그널 등을 카테고리별로 정리. 이해도 상태(모름 / 헷갈림 / 이해함) 토글 가능
- **💻 코드 스니펫** — 자주 쓰는 GDScript 패턴을 구문 강조와 함께 저장. 복사 버튼 지원
- **🖱️ How-to** — 에디터 조작, 프로젝트 설정, 에셋 임포트 등 "어떻게 하는지" 단계별 정리
- **🔧 트러블슈팅** — 증상 → 원인 → 해결책 형태로 에러 기록
- **🗺️ 학습 로드맵** — 주차별 체크리스트로 진도 추적 (진행률 자동 계산)

부가 기능:

- 🌓 다크/라이트 테마 전환
- 🔍 실시간 검색 + 카테고리 필터
- 📌 자주 보는 항목 상단 고정 (핀)
- 💾 JSON 내보내기/불러오기 (백업/기기 이동용)
- 📱 PWA 지원 — 홈 화면에 설치하면 네이티브 앱처럼 오프라인에서도 동작
- ⌨️ 완전 반응형 — 모바일, 태블릿 분할 화면 대응

## 🚀 시작하기

### 방법 1: GitHub Pages로 바로 배포 (추천)

1. 이 저장소를 fork 또는 clone
2. GitHub 저장소의 **Settings → Pages** 로 이동
3. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `root` 로 설정
4. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속 가능

### 방법 2: 로컬에서 실행

```bash
# 그냥 파일을 브라우저로 열어도 동작하지만,
# Service Worker(PWA)를 테스트하려면 로컬 서버가 필요합니다.

# Python 3 기준
python3 -m http.server 8080

# 또는 Node.js
npx serve .
```

그 다음 `http://localhost:8080` 접속.

### 방법 3: 앱처럼 설치 (PWA)

위 방법으로 접속한 뒤, 크롬/엣지 주소창 오른쪽의 **설치** 아이콘 클릭.  
또는 모바일 브라우저의 "홈 화면에 추가" 메뉴 사용.

## 💾 데이터 관리

- **저장 위치**: 브라우저의 `localStorage` (외부 서버 없음, 광고 없음)
- **백업**: 화면 우측 상단 "내보내기" 버튼 → JSON 파일 다운로드
- **복원/이전**: "불러오기" 버튼 → 내보냈던 JSON 선택
- **다른 기기로 옮기기**: 내보낸 JSON을 다른 기기에서 불러오기

> ⚠️ 브라우저 데이터를 지우면 저장된 내용도 함께 사라집니다. 중요한 내용은 주기적으로 JSON으로 내보내 두세요.

## 🛠️ 기술 스택

- **Vanilla JavaScript** — 프레임워크 없음, 빌드 도구 없음
- **HTML + CSS + JS 단일 파일** — 수정/배포가 매우 간단
- **Service Worker** — 오프라인 동작 + 자동 캐시 갱신
- **localStorage** — 클라이언트 사이드 저장
- **[Moneygraphy](https://moneygraphy.com)** — 한글 UI 폰트

## 🔄 업데이트 방법

`sw.js` 파일 상단의 `CACHE_VERSION` 값을 올리면 기존에 설치한 사용자들도 자동으로 새 버전을 받습니다.

```js
const CACHE_VERSION = 'v1.0.0'; // → 'v1.0.1' 로 변경
```
