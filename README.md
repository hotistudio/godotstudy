# 🤖 Godot 학습 도우미

## ✨ 기능

### 📖 용어/개념 (44개 수록)
- Godot 핵심 용어: 노드, GDScript, 물리, UI, 시그널
- 2D 횡스크롤 관련: Camera2D, TileMap, ParallaxBackground, RayCast2D, 상태머신
- 대화창 관련: RichTextLabel, visible_characters, NinePatchRect
- 아이템/상호작용: input_event, mouse_entered/exited, @export Array
- 학습 상태 표시: **모름 → 헷갈림 → 이해함** (클릭으로 전환)
- 내 메모 추가 가능

### 💻 코드 스니펫 (35개 수록)
- **캐릭터 조작**: 기본 이동, 점프, 벽 슬라이드/벽 점프, 코요테 타임+점프 버퍼, 대시
- **전투**: 상태머신, HitBox/HurtBox, HP 시스템, 무적 시간, 카메라 쉐이크
- **적 AI**: 순찰→추적→공격, 보스전 (페이즈 전환)
- **아이템**: 자동 줍기, 클릭 줍기, 키보드(F키) 줍기, 서랍/상자 조사, 숨겨진 아이템, 아이템 사용, 인벤토리 시스템
- **대화**: 대화창 시스템, 타이핑 효과, 선택지 분기, JSON 데이터 로드
- **연출**: 컷씬, 패럴랙스 배경, 등장/퇴장 애니메이션
- **시스템**: 세이브/로드, 씬 전환, 스위치+문 퍼즐, 열쇠/잠긴 문, 상호작용(E키)
- **GDScript 신택스 하이라이팅** + 원클릭 코드 복사

### 🖱️ How-to 가이드 (23개 수록)
- **기본**: 프로젝트 생성, 노드 추가, 스크립트 붙이기, Input Map, 씬 실행
- **레벨 디자인**: TileMap으로 레벨 만들기, Camera2D 설정, 패럴랙스 배경
- **전투 세팅**: HitBox/HurtBox 충돌 레이어, 적 캐릭터 씬 구성, 보스 HP바
- **아이템**: 클릭 가능한 아이템, 서랍/상자 조사 오브젝트, ItemDB 만들기
- **시스템**: Autoload 등록, 세이브 포인트, 인벤토리 UI, 단서/퍼즐 플래그 관리
- **대화창**: UI 구성, 초상화 넣기, 폰트 설정
- **기타**: 스프라이트 애니메이션, 원격 디버깅

## 🚀 사용 방법

### 그냥 쓰기
`index.html` 파일을 브라우저에서 열면 바로 사용 가능합니다.  
별도 서버나 설치가 필요 없어요.

### GitHub Pages로 배포하기

1. 이 리포지토리를 Fork하거나, 새 리포지토리를 만들어 파일을 업로드
2. 리포지토리 **Settings** → **Pages**
3. Source를 **Deploy from a branch**로 선택
4. Branch를 **main**, 폴더를 **/ (root)** 로 선택 후 Save
5. 1~2분 후 `https://유저이름.github.io/리포지토리이름/` 에서 접속 가능!

### 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 메인 앱 |
| `manifest.json` | PWA 설정 (앱 이름, 아이콘, 테마) |
| `sw.js` | 서비스워커 (오프라인 캐싱) |
| `icon-192.png` | PWA 아이콘 (192x192) |
| `icon-512.png` | PWA 아이콘 (512x512) |
| `README.md` | 이 문서 |

## 💾 데이터 저장

- 모든 데이터는 **브라우저 localStorage**에 자동 저장됩니다.
- 다른 기기로 옮기려면 **↓ 내보내기**로 JSON 파일을 저장한 뒤, 다른 기기에서 **↑ 불러오기**로 불러오세요.
- **↺ 초기화** 버튼으로 기본 데이터로 되돌릴 수 있습니다.
- 새 버전에서 기본 데이터가 추가되었다면 초기화 후 반영됩니다.
